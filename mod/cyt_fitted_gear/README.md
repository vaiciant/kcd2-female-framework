# Fitted Gear for Female Framework

by Cytyryz

The framework puts the woman in the game but all the armor was still made for henry, so on her the shoulders are too wide, its baggy at the waist and it floats off her back. This refits all of it to her body.

What I refit:

- Short gambeson, slimmed down, everything else is fitted around this one
- Padded hose, sits back where it should and the hips are narrower
- Arm armor, plate and brigandine
- Cuirasses, I kept the normal shape and shrunk it down to her size. The chest is flat because its metal and it would push her chest in, anything else just isnt realistic
- Brigandines
- Mail shirts, short and long
- Long gambesons, caftans, coats, waffenrocks and habits
- Hoods (works with Hood On too), coifs and collars

Helmets arent in here since the framework already has those fixed.

## How it works

None of the original items are changed so NPCs look the same as always. Every item gets a fitted copy with the same stats and the same name with `_ff` on the end. When she has the normal one in her inventory it gets swapped for the copy, it uses the same list the framework already uses for the dresses. If something was equipped when it swapped just put it back on.

Armor you buy, loot or get from the story all swaps too, and theoretically even armor henry cant get in game and can only be grabbed from console commands should fit her as well.

You can also spawn the copies yourself, all the names are in spawn_list.txt

    wh_cheat_addItem Cuirass03_m03_A5_ff

## Install

You need KCD2 Female Framework 0.4.0 or newer. I made it on 0.4.0 but 0.5.0 works the same since nothing it uses changed. Drop the `cyt_fitted_gear` folder in your Mods folder (or install the zip with Vortex) and start the game.

If things dont swap type `cyt_gear_log` in the console, it should say the list is in the framework and that she is a woman.

## Known issues

- The gambeson lacing at the top can poke through a coif a tiny bit if you dont have a cuirass on
- zizka's coif doesnt sit as clean as the others
- Kettle hats 04 and 05 push the coifs out a bit without a cuirass, thats the games own morph doing that
